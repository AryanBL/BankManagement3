BankManagement Postman API Testing Guide

Use this file to test the backend APIs in Postman. Base URL: http://127.0.0.1:4000. For protected routes, include the session token returned by the login API.

Postman variables to create: 
{{baseUrl}} = http://127.0.0.1:4000
{{token}} = sessionToken returned by login
{{highAdminToken}} = HighAdmin sessionToken
{{customerToken}} = Customer sessionToken
{{accountID}} = account ID from your database/API response
{{customerID}} = customer ID from your database/API response
{{employeeID}} = employee ID from your database/API response
{{branchID}} = branch ID from your database
{{loanID}} = loan ID from your database/API response
{{installmentID}} = installment ID from your database/API response
{{transactionID}} = transaction ID from your database/API response

Authorization header format: Authorization: Bearer {{token}}. Keep the word Bearer and replace only the token value.
